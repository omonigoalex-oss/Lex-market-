LEX MARKET — ADMIN SETUP

The Admin Dashboard is protected by Firestore rules. You cannot make yourself an admin from the public website.

ONE-TIME ADMIN BOOTSTRAP
1. Create/sign in to your normal LEX Market account first.
2. Open Firebase Console.
3. Go to Firestore Database > Data.
4. Open the users collection.
5. Find your user document. The document ID is your Firebase Authentication UID.
6. Change the field:
   role: customer
   to:
   role: admin
7. Save it.
8. From the LEX Market home page, go to Settings and tap the small “LEX MARKET” label once to open the hidden control center.
9. Sign in with that same account.

After the role is admin, the Admin Dashboard can securely:
- View customers and sellers
- Review seller applications
- Approve or reject sellers
- Review seller products
- Approve or reject products
- View orders
- Update order status

IMPORTANT
Never set the admin role through public client-side code. Keep the role change as a controlled Firebase Console action.


NOTE: The Firestore rules also recognize the designated admin email for this project so the admin dashboard can read all required collections without the recursive users-role permission problem. If your Firebase admin account uses a different email, update the email in firebase-rules.txt before publishing.
