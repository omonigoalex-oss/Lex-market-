Firebase Setup

This build is Firebase-ready. Follow the steps below once to connect your own project.

  1. Create a Firebase project.
  2. Add a Web app and copy its configuration object.
  3. Paste the values into firebase-config.js.
  4. In Authentication, enable Email/Password.
  5. Create a Firestore Database.
  6. Paste the starter rules from firebase-rules.txt.
  7. Open auth.html and create your first account.
  8. For admin access, create the account first, then change that user's Firestore profile role to admin from the Firebase console.
Important: Do not put service-account private keys in this website. The Firebase Web config is designed to be used in client-side apps; access control comes from Firebase Authentication and Security Rules.
